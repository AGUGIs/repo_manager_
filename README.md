## О чём проект

Сервис хранит сведения о git-репозиториях внутри учебных проектов:
кто владелец, какой репозиторий привязан, какие участники имеют право
на запись.

## Сущности

- пользователь
- проект
- репозиторий
- участник

## Что уже сделано

Файл `main.py` проверяет режим доступа к репозиторию, считает срок
существования проекта, решает, может ли участник делать push, и печатает
сокращённый URL клонирования. Использованы функции, переменные,
операторы сравнения и модуль `datetime`.

## Функции

- `visibility_text(private_flag)` — по флагу приватности возвращает
  подпись режима доступа: ограниченный или открытый для просмотра.
- `days_since_create(start, current)` — по двум датам считает, сколько
  дней существует проект.
- `can_push(role)` — проверяет право участника на запись. Push разрешён
  ролям `owner` и `maintainer`, остальным запрещён.
- `short_url(url)` — сокращает адрес клонирования при печати: если
  строка короче 18 символов, возвращает `скрыто`, иначе оставляет
  начало и конец адреса, середину заменяет на `***`.

## Запуск

```bash
python3 main.py
```
