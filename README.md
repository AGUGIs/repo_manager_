# Сервис управления репозиториями проектов

Консольное приложение для учёта учебных проектов, git-репозиториев
и прав участников. Практическая работа № 2 по дисциплине
«Технологии разработки приложений на базе фреймворков».
Студент: Челышев Кирилл, ЭФБО-10-24.

## Возможности

- просмотр и поиск проектов, репозиториев и пользователей;
- проверка режима доступа к репозиторию;
- проверка права участника на push;
- добавление и удаление участников;
- добавление пользователей;
- статистика по репозиториям и ролям;
- карточка проекта из сценария ПР1.

## Структура проекта

- `main.py` — точка запуска и меню;
- `users.py` — работа с пользователями;
- `projects.py` — работа с учебными проектами;
- `repositories.py` — работа с git-репозиториями;
- `members.py` — работа с участниками;
- `storage.py` — сохранение и загрузка JSON;
- `utils.py` — безопасный ввод;
- `data/` — JSON-файлы данных;
- `tests/` — автоматизированные тесты.

Пользователь — отдельная сущность: логин и ФИО хранятся в `users.py`.
Проект ссылается на владельца через `owner_id`, участник репозитория —
через `user_id`. Роль остаётся у участника, потому что это связь
«человек — репозиторий», а не свойство человека.

## Формат данных

Данные хранятся в каталоге `data/` в формате JSON:

- `projects.json` — учебные проекты;
- `repositories.json` — репозитории;
- `members.json` — участники и роли;
- `users.json` — пользователи.

Пример записи репозитория:

```json
{
  "id": 1,
  "project_id": 1,
  "name": "course-notes",
  "clone_url": "https://gitlab.local/course-notes.git",
  "private": false
}
```

## Требования

- Python 3.x;
- pytest;
- flake8;
- autopep8;
- mypy.

Установка зависимостей:

```bash
pip install -r requirements.txt
```

## Запуск программы

```bash
python3 main.py
```

## Запуск тестов

```bash
pytest
```

## Проверка качества кода

Сначала autopep8 приводит код к PEP 8, затем flake8 проверяет результат:

```bash
make format
make lint
make typecheck
```

Или всё сразу: форматирование, flake8, mypy и тесты:

```bash
make check
```

Без Makefile:

```bash
autopep8 --in-place --recursive --max-line-length 79 --exclude .venv .
flake8
mypy main.py projects.py repositories.py members.py users.py storage.py utils.py
```

## Сценарий ПР1

Функции `visibility_text()`, `days_since_create()`, `can_push()` и
`short_url()` сохранены и используются в новых модулях. Пункт меню
«Карточка проекта» повторяет вывод начального сценария ПР1 по данным
из JSON.
